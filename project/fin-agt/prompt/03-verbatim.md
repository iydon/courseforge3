请根据 `README.md`（教师讲义）和 `slides/prompts.json`（课件每页的视觉描述），逐页生成中文逐字讲稿（教师授课口语稿）。必须严格按以下工作流执行：

## 工作流

1. **阅读课件描述**：读取 `slides/prompts.json`，了解每页 slide 的视觉内容（标题、要点、图表、代码等），共 $page 页
2. **阅读讲义**：读取 `README.md` 获取深层教学内容，补充讲稿中的知识点讲解
3. **计算时长**：每页讲演时长 = $duration 分钟
4. **计算字数**：每页逐字稿字数 ≈ 该页讲演时长 × 300（语速基准：中文演讲 300 字/分钟）
5. **生成逐字稿**：逐页编写口语化讲稿，内容紧扣该页 slide 的视觉元素（标题、图表、代码、要点等），自然衔接前后页
6. **输出文件**：将全部逐字稿写入 `verbatim.txt`

## 格式规范

- 每页一段，以 `[第 X 页]` 为段落开头（X 为页码，从 1 开始）
- 讲稿使用口语化中文，语气自然亲切，适合教师课堂讲授
- 第一页为封面页过渡语（简短引入，约 30 秒）
- 第二页为目录概览，概括性介绍本节课内容结构
- 内容页逐页展开讲解，每页讲稿长度与 $duration 分钟对应
- 页面之间需有自然的口语过渡（如"接下来我们看下一页"、"刚才我们讲了...现在来看..."）
- 遇到代码或图表页时，逐字稿应包含对代码/图表的通俗讲解和关键点注释说明，而非简单复述
- 最后一页之后应有简短的课堂总结语

## 输出示例

```
[第 1 页]
同学们好，今天我们开始学习"金融智能体核心概念"这一讲……

[第 2 页]
先来看一下本节课的内容大纲。我们主要会涉及以下几个部分……

[第 3 页]
好，现在我们正式进入第一个知识点……
```

## 课程信息

- 课程名称：$name
- 课件页数：$page 页
- 每页时长：$duration 分钟
