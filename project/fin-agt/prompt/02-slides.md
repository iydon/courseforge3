请根据 `README.md`（本课时教师讲义），生成一套教学课件。课件以图片形式生成，最终合并为 PDF。必须严格按以下工作流执行，不得跳过验证环节：

## 工作流

1. **创建目录**：`mkdir -p slides/image`
2. **编写提示词**：在 `slides/prompts.json` 中写入每一页的图像生成提示词，JSON 格式为字符串列表 `["第1页提示词", "第2页提示词", ...]`，共 $page 个元素（索引 0 对应第 1 页）
3. **生成课件**：在 `slides/` 目录下运行 `uv run gpt_image.py`，逐页生成图片到 `image/` 并自动合并为 `main.pdf`
4. **修复重试**：若生成失败，检查错误信息修正 `slides/prompts.json`，重新执行步骤 3，直至 `slides/main.pdf` 生成成功

所有文件读写和命令执行均以当前课程目录为工作目录。

## 页面结构

必须严格按以下顺序生成共 $page 页：

- **第 1 页（titlepage）**：封面页，仅包含课程名称 `$name`（大标题）和副标题（可提炼自内容要点），整体风格庄重专业，不出现课时长度、主讲人等个性化信息
- **第 2 页（tableofcontents）**：目录/大纲页，列出本节课的知识要点大纲（3-6 条），采用编号列表布局
- **第 3～$page 页（content）**：内容页，根据 README.md 中的教学内容逐页展开，每页聚焦一个知识点或子主题

## 视觉风格规范（所有页面必须一致）

- **整体风格**：现代科技风格，浅色背景为主，简洁清爽，适合高校课堂教学
- **配色方案**：白色/浅灰（#f5f7fa / #ffffff）为底色，深蓝（#1565c0 / #1e3a5f）用于标题和重点元素，辅以浅蓝（#42a5f5 / #bbdefb）点缀，正文深灰（#333333）
- **背景**：所有页面使用统一的浅色渐变背景，可带有极淡的抽象科技元素（如数据节点、网格线、科技感几何图形），不可喧宾夺主
- **排版**：
  - 标题：大号深蓝（#1565c0）粗体，居中或左对齐（封面页居中，内容页左对齐），字体风格现代无衬线
  - 正文：深灰（#333333），字号适中，行距舒适，左对齐
  - 重点内容使用深蓝或蓝色高亮强调
  - 页面留白充足，避免信息过密
- **封面页特殊要求**：标题占据视觉中心，背景可加入金融相关抽象元素（K 线图剪影、数据流线条等），浅色科技感
- **内容页结构**：顶部标题栏（白色背景+深蓝色标题文字，细线分隔），下方内容区域（要点列表/图表说明/代码片段等）
- **代码/术语展示**：代码使用等宽字体浅灰底块（如 #f0f4f8），深色文字，语法高亮
- **图表**：若有数据可视化需求，描述图表的类型（柱状图/折线图/饼图等）、配色与标注，保持与整体风格协调
- **禁止元素**：不得出现任何品牌 logo、真实公司名称（除教学内容需要外）、低俗或不相关图像

## 提示词编写规范

- 每个提示词必须完整描述该页的视觉呈现，包括布局、文字内容、配色、图形元素、排版方式
- 提示词使用中文描述，具体文字内容需明确给出
- 页码和页脚不需要在提示词中描述（由生成流程自动处理或省略）
- 所有提示词必须显式指定"16:9 横版比例"
- 避免在提示词中使用"像...一样""参考...风格"等模糊表述，需用具体视觉元素描述
