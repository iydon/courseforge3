请根据 `slides/section.typ` 的课件内容，以及 `slides/main.pdf` 的渲染出来的 PDF 课件内容，逐页（frame）生成中文逐字讲稿（教师授课口语稿）。必须严格按以下工作流执行：

## 工作流

1. **计算时长**：每页讲演时长 = $duration 分钟
2. **对齐页码**：用 `pdfinfo main.pdf` 获取总页数；无法直接查看 PDF 内容时，用 `pdftotext -layout main.pdf -` 按分页符（\f）分段提取每页文字对照
3. **计算字数**：每页逐字稿字数 ≈ 该页讲演时长 × 300（语速基准：中文演讲 300 字/分钟）
4. **生成逐字稿**：逐页编写口语化讲稿，以该页内容（标题、图表、代码、要点等）为引子展开讲授（要求见下文），页与页之间自然衔接
5. **输出文件**：将全部逐字稿写入 `verbatim.txt`

## 内容要求（重要）

- 不要照着屏幕念：禁止复述或朗读页面上的文字与代码；页面内容只作为引子，讲稿围绕该页主题展开讲授，交代背景与动机、解释原理与取舍、指出常见误区
- 主动拓展知识面：可以讲授课件中没有展开的内容，比如相关概念、发展脉络、工程实践中的经验与教训、与相邻知识点的关系；拓展必须与该页主题相关且真实准确
- 允许并鼓励抽象：从本页具体内容中提炼通用的方法论、设计原则或经验法则，体现讲授者的专业积累与行业视野
- 发挥要自然：像真实课堂的临场讲授，可用设问、举例、类比、对比等方式，不必刻意使用比喻，避免千篇一律的句式与结构
- 严谨性：不得编造事实、数据、论文、人名或工具行为；不确定的内容不要写
- 拒绝凑字数：不靠寒暄、重复标题或过渡语灌水，每页都要有实质信息量

## 格式规范

- 每页一段，以 `[第 X 页]` 为段落开头（X 为页码，从 1 开始）
- 讲稿使用口语化中文，语气自然亲切，适合教师课堂讲授
- 页面之间需有自然的口语过渡（如"接下来我们看下一页"、"刚才我们讲了...现在来看..."）
- 遇到代码页时，逐字稿应包含对代码的通俗讲解和关键行注释说明，而非简单复述

## 输出示例

```
[第 1 页]
大家好，今天我们来学习……

[第 2 页]
上一页我们介绍了……接下来我们深入看一下……

[第 3 页]
这一页展示了一段核心代码，我来逐行给大家讲解一下……
```

## 风格约束（必须遵守）

- 去 AI 味：讲稿避免使用破折号（——）、引号、括号、箭头（→、->）、单横杠等非必要符号（对话的引号可以保留，代码、命令等其他特殊情形也可以酌情保留）。
- 不布置作业、课后练习或思考题。
- 不出现课时时长、时间分配、课时序号等课程元信息，不要出现"这页大概讲几分钟"之类表述。
- 讲稿必须自成体系，单独使用即可上课：不引用其他课时，不假设学生学过其他课时。
